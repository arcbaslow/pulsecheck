# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue for a possible data leak, unsafe export or credential exposure.

Include the affected version, a minimal sanitized reproduction and the expected
behavior. Do not attach a real Pulsecheck dump unless every sensitive value has
been removed.

The current `0.1.x` line is alpha software. Security fixes are made on the latest
release rather than backported to older alpha builds.
